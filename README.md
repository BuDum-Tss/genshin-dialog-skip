# Genshin Skip

Небольшая программа для Windows, которая сидит в трее и пропускает диалоги в Genshin Impact:

- **Скипать диалог** — видит золотой ромбик «продолжить» внизу экрана и нажимает пробел.
- **Скипать выбор** — когда в диалоге появляется список вариантов ответа, нажимает F и выбирает первый вариант.

Работает «поверх» игры: делает снимки окна, распознаёт нужные элементы по картинке и эмулирует нажатия клавиш. В память и файлы игры не вмешивается.

## Установка

1. Скачайте `GenshinSkip.exe` из [Releases](../../releases/latest). Больше ничего не нужно — Python и библиотеки внутри.
2. Запустите. Windows спросит права администратора — **подтвердите**: игра обычно запущена от администратора, и без этого Windows не пропустит нажатия клавиш.
3. В трее появится золотой ромбик (рядом с часами, возможно под стрелкой «скрытые значки»).

## Меню в трее (правый клик)

| Пункт | Что делает |
|---|---|
| Режим скипа диалога → Скипать диалог | галка: нажимать пробел по ромбику |
| Режим скипа диалога → Скипать выбор | галка: нажимать F на первом варианте ответа |
| Остановить всё | галка: пауза обеих функций (двойной клик по иконке — то же самое) |
| Выход | закрыть программу |

Иконка золотая — работает, серая — остановлено (пауза или обе галки сняты).

## Требования и ограничения

- Windows 10/11, Genshin Impact в оконном или безрамочном режиме (в «настоящем» полноэкранном захват экрана может не работать).
- Окно игры должно называться «Genshin Impact» и быть активным — иначе программа ничего не нажимает.
- Протестировано на русском клиенте. Шаблоны подобраны по разрешению 1128×634 и масштабируются; на 1920×1080 распознавание проверено.
- «Скипать выбор» нажимает F только когда видны и кнопки диалога («Авто», список и т. д.), и значок F у варианта ответа, поэтому не должно срабатывать на подсказках в открытом мире. Если всё же срабатывает — создайте issue со скриншотом.

## Сборка из исходников

```bash
build.bat
```

Результат — `dist\GenshinSkip.exe`. Или просто `python genshin_skip.py` после `pip install -r requirements.txt` (от администратора, если игра запущена от администратора).

## Отказ от ответственности

Сторонние программы, автоматизирующие игру, могут нарушать правила Genshin Impact / HoYoverse и привести к санкциям для аккаунта. Проект не связан с HoYoverse и предоставляется «как есть». Используйте на свой риск.
